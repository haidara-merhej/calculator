# Calculator

A simple console-based calculator built with C#. The program allows users to perform basic arithmetic operations through a command-line interface.

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Validates numeric input
- Validates the selected operator
- Prevents division by zero
- Allows users to perform another calculation or exit

## Requirements

- [.NET SDK](https://dotnet.microsoft.com/download) installed
- A terminal or command prompt

### 2. Run the project

If your project contains a `.csproj` file, run:

```bash
dotnet run
```

Alternatively, open the project in your preferred C# IDE and run it there.

## How to Use

1. Run the program.
2. Enter the first number.
3. Enter the second number.
4. Choose an operator: `+`, `-`, `*`, or `/`.
5. Read the result displayed in the console.
6. Press **Enter** when prompted to perform another calculation. Press another key to exit.

If you enter an invalid number or operator, the program displays an error message and asks you to try again. Division by zero is not allowed.

## Example


## Implementation

The calculator uses separate methods for each arithmetic operation:

- `Add()` — adds two numbers
- `Subtract()` — subtracts the second number from the first
- `Multiply()` — multiplies two numbers
- `Divide()` — divides the first number by the second
- `Calculate()` — selects the appropriate operation based on the chosen operator
